# SISTEMA-INVENTARIO
El sistema representa los productos mediante un arreglo lineal (clases Producto e Inventario) y el stock por almacén mediante un arreglo bidimensional, implementa manualmente una búsqueda secuencial y una búsqueda binaria, y compara experimentalmente ambos algoritmos con distintos tamaños de datos (100, 1 000, 10 000 y 100 000 productos)
